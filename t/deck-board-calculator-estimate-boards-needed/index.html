Deck Board Calculator – Estimate Boards Needed





How it works

Boards per row = ceil(Deck Length (in) ÷ Board Width (in))
Rows needed = ceil(Deck Width (in) ÷ (Board Width (in) + Spacing (in)))
Total boards = Boards per row × Rows needed

FAQ

What units do I need to use?
Deck dimensions are in feet, board width and spacing are in inches.
Do I need to add extra boards for cuts?
It’s a good idea to purchase 10–15 % extra boards to cover cuts and mistakes.
Can I use this calculator for irregular deck shapes?
For non‑rectangular decks, estimate each rectangular section separately and add the totals.
